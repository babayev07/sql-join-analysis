# SQL JOIN Analysis Project

## Description
This project demonstrates how to analyze data using multiple related tables.

## Tables
- wells: basic information about wells
- production: daily production data
- reservoirs: reservoir details

## Tasks
- Join tables using well_id
- Analyze production per well
- Aggregate data by location
- Combine technical and production data

## Tools
- SQL

## Goal
To demonstrate ability to work with relational data and perform JOIN operations.
